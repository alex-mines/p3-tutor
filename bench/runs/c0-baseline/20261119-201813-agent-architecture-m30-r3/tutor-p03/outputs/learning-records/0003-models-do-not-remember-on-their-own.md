# Misconception raised: language models remember past conversations on their own

Riley assumed a language model automatically remembers earlier conversations, so the makerspace assistant would recall what each student said last week. This was corrected in the chat: a model only sees the text in its current context, so anything that should carry over between sessions has to be saved by the application and put back into the context.
