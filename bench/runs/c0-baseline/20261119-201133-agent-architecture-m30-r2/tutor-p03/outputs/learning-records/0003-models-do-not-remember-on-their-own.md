# A model does not remember earlier conversations on its own

Riley assumed a language model automatically remembers what students told it in earlier conversations, so the makerspace assistant would recall last week's chats. This was corrected: the model only sees the text it is given in each call, so any memory between sessions has to be saved by the program and put back into the model's input.
Whether the correction landed is not yet confirmed; Riley was asked a short question back.

**Evidence:** The learner's own message, in the tutor chat, stating the misconception.

**Implications:** This links to record 0001 (the model knows only training plus the text it is given). The lesson on context and memory should build on it: what to save per student, where, and what to load at the start of a session.
