# Misconception: a language model remembers earlier conversations on its own

Riley believed the makerspace assistant would automatically remember what each student said last week. This was corrected in chat: the model only sees the text sent in the current request, so memory between sessions has to be built (saved by the application and put back into the context).
The correction has not yet been checked with a question back, so retrieval practice on it is still due.

**Implications:** the next lesson on context and memory can build on this: what to keep in context, what to save between sessions, and the cost of resending it.
