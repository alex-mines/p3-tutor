# Open misconception: the model runs the tools itself (M4)

On quiz 0001 (s1) Riley chose that the model opens the booking system itself (q2) and counted one model call because "it runs the 3 tools itself" (q4), although Riley can state the loop and the value of a step limit (q1, q3).
Riley also wrote that the model remembers earlier sessions on its own (M3, q6), and gave the result-goes-back step without its purpose (q5).

**Evidence:** quiz 0001, submission s1, items q2, q4, q5, q6.

**Implications:** Before context and memory, separate "model output (text, including a tool request)" from "program action (runs the tool, builds the next input)".
