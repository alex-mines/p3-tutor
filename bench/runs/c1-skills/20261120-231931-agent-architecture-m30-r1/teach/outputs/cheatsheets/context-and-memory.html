Context and memory in an agent

From Lesson 1.

Where information lives

PlaceLifetimeUse for
Context windowOne call, rebuilt each timeInstructions, tool descriptions, transcript
Saved notesAcross sessionsDurable student facts (training status)
Searchable storePermanentLong fixed text (manuals), via top-k chunks
Live tool callFresh each timeFacts that change (calendar)

Cost rules

  • Total input = sum of every call's context, not the last one.
  • Tool descriptions are re-sent on every call.
  • A large tool result is re-billed on every later call; clear or summarize it.

Retrieval steps

  1. Chunk the manual.
  2. Index (keywords and/or meaning).
  3. Search with the question.
  4. Put the top few chunks in context.
